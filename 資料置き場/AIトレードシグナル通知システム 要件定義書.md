# AIトレードシグナル通知システム 要件定義書

値動きを常時監視し、AIが「買い目（押し目・反発など）」を検知したら Discord に通知するシステムの要件をまとめる。

**構成方針**\: Java \= システム基盤・制御 / Python \= AIエンジン / Discord \= 通知チャネル

Table of Contents

* * *

## 01\. 全体アーキテクチャ

### 外部データソース

| 区分 | ソース |
| --- | --- |
| 暗号資産 | BINANCE / Bybit / Coinbase ほか |
| 株式・金融 | Yahoo Finance / Kabutan / MarketWatch |

### Java（システム基盤・制御）

| モジュール | 責務 |
| --- | --- |
| データ取得 | REST API 通信 / WebSocket 通信 / エラー処理 / リトライ処理 / データ正規化 |
| データ管理 | 保存・更新・削除 / データクレンジング / バックアップ / データ整合性 |
| リアルタイム監視 | マルチタイムフレーム / 条件監視・検知 / アラート生成 / Python へ分析依頼 |
| バックテスト実行 | 期間指定 / パラメータ指定 / Python に実行指示 / 結果取得・保存 |
| 通知システム | Discord 通知 / Webhook 通信 / Bot 管理 / 通知履歴管理 |
| 自動売買（将来） | 注文発注 / ポジション管理 / リスク管理 / 資金管理 |

### データベース

- 開発環境: SQLite → 本番環境: PostgreSQL
- 価格データ（OHLCV）・出来高・特徴量・学習データ

- 特徴量生成・AI 学習・AI 推論

- Webhook 経由で、売買シグナル通知 / アラート通知 / レポート通知 / エラー通知をユーザーへ配信

### データフロー

```

                                 ▲  │

                                 │
```

## 02\. データ取得要件（Java）

### 取得対象

| 区分 | 対象 |
| --- | --- |
| 暗号資産 | Binance API / Bybit API / Coinbase API |
| 株式・金融 | Yahoo Finance / Kabutan / MarketWatch |
| その他（将来） | ニュース API / SNS API（X 等）/ オンチェーンデータ / ETF 資金流入データ |

### 取得データ

- OHLCV（始値・高値・安値・終値・出来高）

- 資金調達率
- 経済指標・金利

- REST API（定期取得）

- データ欠損時の補完処理

| 項目 | 形式 |

| 板情報 | テーブル / JSON |
| 経済指標 | テーブル |
| ニュース | テーブル / JSON |

## 03\. リアルタイム監視要件（Java）

### 監視対象

- タイムフレーム: 5 分足 / 15 分足 / 1 時間足 / 4 時間足 / 日足
- 複数銘柄の同時監視

### 監視条件（例）

| 分類 | 条件 |
| --- | --- |
| 価格条件 | 移動平均線との乖離 / サポート・レジスタンス到達 |
| テクニカル条件 | RSI \< 30 / MACD ゴールデンクロス / ボリンジャーバンド下限接触 |
| 出来高条件 | 出来高急増（平均比 ○ 倍） |
| その他条件 | 高値更新・安値更新 / ボラティリティ急上昇 |

### 処理フロー

1. 新規データ受信（WebSocket）
2. 条件評価エンジン
3. 条件一致を検知
4. Python へ分析依頼
5. 分析結果を受信
6. 通知 or ログ記録

### 要件

- ミリ秒単位のリアルタイム処理
- 監視遅延 3 秒以内
- 同時監視銘柄 100 銘柄以上
- 検知ロジックの設定可能
- 監視停止・再開の制御
- 障害時の自動復旧

### 出力

- Python 分析リクエスト
- Discord 通知（条件一致時）

- Sharpe Ratio
- 最大ドローダウン
- 年間リターン
- 精度・再現率・F1 スコア

### 要件

- 学習の自動化（スケジュール実行）
- モデルのバージョン管理
- モデルの自動更新・切替
- 学習結果のログ記録

## 07\. バックテスト要件（Python / Java 連携）

### 入力（Java から）

- 銘柄
- 期間（開始日〜終了日）
- タイムフレーム
- 初期資金
- 手数料・スリッページ
- 売買ルール / パラメータ

### 処理フロー

1. 過去データ取得（DB）
2. 特徴量生成
3. AI 推論（シグナル生成）
4. 売買シミュレーション
5. パフォーマンス計算
6. 結果を DB に保存
7. 結果を Java へ返却

### 出力（結果）

- 総利益
- 総取引回数
- 勝率
- Profit Factor
- 最大ドローダウン
- Sharpe Ratio
- 年率リターン
- 取引履歴（一覧）
- グラフデータ

### 要件

- 高速処理（並列計算）
- 複数パラメータの同時検証
- レポート自動生成（CSV / HTML）
- 結果の可視化（チャート）

## 08\. Discord 通知要件（Java）

### 通知対象

- 売買シグナル
- 押し目・反発検知
- ブレイクアウト検知
- 急騰・急落アラート
- 指定価格到達
- トレーリングストップ発動
- AI モデル学習完了
- バックテスト完了
- システムエラー
- 日次・週次・月次レポート

### 通知内容（例）

```
【BTCシグナル】
銘柄        : BTC/USDT
現在価格    : 16,240,000 円
AI反発確率  : 84%
RSI         : 28
MACD        : ゴールデンクロス
推奨        : 押し目買い候補
利確目標    : 16,750,000 円
損切り目安  : 15,980,000 円
リスクリワード: 3.8
信頼度      : A
2024-05-20 15:30
```

### 要件

- Webhook 通信
- メッセージのフォーマットテンプレート
- 画像（チャート）の添付
- 通知の頻度制御（重複防止）
- 通知履歴の保存
- 障害時の再送機能

### 将来: Discord Bot コマンド

| コマンド | 内容 |
| --- | --- |
| `/price BTC` | 現在価格を表示 |
| `/signal BTC` | 直近シグナルを表示 |
| `/report` | レポート出力 |
| `/status` | システム稼働状況 |
| `/backtest` | バックテスト実行 |
| `/model` | モデル情報・切替 |

※ 上記のほか、随時コマンドを追加
